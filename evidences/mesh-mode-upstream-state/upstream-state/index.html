Mesh mode: upstream state (2026-10-21T10:08:03Z)¶

Generated by scripts/mesh-mode/check-upstream-state.sh on commit ea5bac7cdf12. Never edited by hand. This is the documentary evidence behind ADR-0009 and the check of its reopen trigger: both conditions below must be met, in released versions, for the decision to be reopened.

Verdict¶

The premises of ADR-0009 hold: SPIRE as the certificate provider is still documented as unsupported in ambient mode, no ztunnel client for the SPIRE agent has merged, and the SPIRE Broker API is still experimental. The decision stays closed.
